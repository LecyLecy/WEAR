# Verification scope

The scaffold is verified by npm run check and a browser smoke check. It does not prove tracking quality.

Add focused automated tests when feature logic exists: coordinate conversion and mirrored alignment, stale-frame rejection, placement composition, single-loop lifecycle, asynchronous product-switch races, and product manifest validation. Do not add tests that only restate type declarations.

Camera realism requires consented live or recorded evaluation. Use the manual protocol in docs/VALIDATION.md. Keep personal footage outside Git and never imply that a fake-camera test proves fit or visual realism.
